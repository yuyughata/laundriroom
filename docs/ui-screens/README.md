# UI screens

Screenshots of every screen in the app, by role, captured on 2026-11-04 from
the current build with demo data (no real customers or vendors). The demo
laundries are in Jos (Fold & Press, Rayfield, with a Terminus branch; Bubble
Wash Terminus, Spotless Tudun Wada, Crisp Laundry Bukuru, PressPoint Angwan
Rukuba). Each PDF starts with an index of its screens; each page shows the
screen's route.

**What changed in this round:** demo data moved to Jos; the rider list
(Vendor → Riders, and the rider picker on a delivery order — migration
`0045`); Admin → Emails (broadcast editor, sending, delivery report —
`0043`/`0044`) and the customer's "Emails from laundriroom" switch; QR codes
with the laundriroom mark, with PNG and PDF downloads, on Admin → Promos,
Vendor → Promos and My page.

The demo data uses a 15% commission, 20% express and 15% premium.
