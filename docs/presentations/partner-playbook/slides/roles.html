There are two kinds of login. The main manager — usually the owner — covers every branch and sees everything, including money: the Ledger, payouts and statements, plus Branches, Team and the payout account. Attendants work the counter: the queue, check-in, stages, handovers, walk-in orders and tags; they can request new item types but can’t approve them, and they never see the business’s money. If you have several shops, you can make someone a manager for one branch only; they run that branch’s orders like an attendant and only see that branch. Riders — your own or a dispatch partner — don’t need an account at all.
