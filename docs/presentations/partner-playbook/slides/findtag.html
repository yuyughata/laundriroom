18

Tags fall off, get torn or go missing. Anyone on the team can deal with it in seconds. Open Tags and use Find a tag at the top: type the full code, or just its number — “42” finds FPL-0042 — or tap Scan and point the camera at it. Tap Missing or Damaged. To replace it, tap Reprint: the same code prints again and goes back into use, so it still matches the item it was on. If a missing tag turns up, tap Found it. The main manager can also reprint all of a batch’s missing and damaged tags at once from the tag history.
