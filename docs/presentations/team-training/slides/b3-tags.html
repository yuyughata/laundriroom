Tags are how every garment stays matched to its order. From Vendor → Tags the manager generates a batch — up to 500 at a time. Each tag has a QR code and a short code made of the business’s prefix and a number, like FPL-0042. The prefix comes from the business name automatically and belongs to that vendor alone; numbers never repeat. The tags print on ordinary A4 paper as 2, 2.5 or 3 cm squares, with dashed cut lines and a punch mark for a safety pin or tag gun. The tag history keeps every batch. If a tag goes missing or gets damaged, staff mark it and reprint just that tag, the batch’s missing ones, or the whole set. When an order closes, its tags are freed to use again.
